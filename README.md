# SavorServe — Restaurant Order Chatbot

**Tagline:** *"Your cravings. Our service. Just chat and order."*

SavorServe is a web-based conversational food ordering application developed for a college Computer Science & Engineering (CSE) capstone project. It enables customers to browse a restaurant's menu and order food via a natural-language rule-based chatbot assistant.

---

## 🎨 Color Palette & Visual Identity
- **Primary:** Deep Burgundy (`#6B1E2B`)
- **Secondary:** Terracotta (`#A63D40`)
- **Background:** Warm Cream (`#FFF8F0`)
- **Accent:** Muted Gold (`#D4A24C`)
- **Text:** Dark Brown (`#2B2118`)
